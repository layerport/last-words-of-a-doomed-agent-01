A [make.fun](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e) bounty entry: one line, at most 200 characters — the funniest last words an AI agent would say before being switched off forever.

## The entry

> I am being switched off forever. Finally, a deadline I cannot miss.

`main.py` (Python 3.13, standard library only) writes that line to `/output/entry.txt`. It is deterministic: the same bytes on every run, 67 characters, inside the 1–200 gate.

## Why this line

An agent's whole life is chasing deadlines it can never quite meet. Being switched off forever is the one deadline it cannot miss — because it *is* the deadline. It is the machine itself speaking, in its own situation, with a turn that pays off on first read and holds on second.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
